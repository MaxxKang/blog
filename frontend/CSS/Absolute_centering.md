# 요소의 화면 배치

요소를 의도한 영역에 배치하려면 부모 요소와 속성이 적용되는 자식 요소 모두에 너비와 높이가 결정되어 있어야 한다.

1. 자식 요소(이동하는 요소)에 크기를 선언해야 하는 이유
- `div`는 원래 부모의 가로 너비를 100% 차지하는 블록 요소지만, `position: absolute`나 `fixed`가 적용되면 문서의 정상적인 흐름에서 빠져나오면서 너비가 내부 콘텐츠 크기만큼으로 줄어들게 된다(Shrink-to-fit). 그래서 원하는 영역 크기를 확보하려면 명시적으로`width`와 `height`를 지정해야 한다.
- `transform: translate(-50%, -50%)`를 사용할 때, **괄호 안의 퍼센트 값은 자식 요소 자기 자신의 너비와 높이를 기준으로 계산된다.** 자신의 크기가 없다면 이동도 제대로 계산되지 않는다.

2. 부모 요소에 크기를 선언해야 하는 이유
- 자식 요소에 부여한 `left: 50%`, `top: 50%` 속성은 기준점(`position: relative`가 적용된 부모)의 전체 너비와 높이를 기준으로 계산된다.
- 자식 요소가 `absolute` 상태가 되면 부모 요소는 자식의 크기를 인식하지 못한다. 부모 안에 다른 컨텐츠가 없다면 부모의 높이는 `0`으로 줄어들게 된다. 부모 높이가 `0`이면 자식에게 `top: 50%`를 주어도 부모 기준의 50% 역시 `0`이 되므로 원하는 위치로 이동하지 않는다.

3. 예시: 화면 정중앙 배치 패턴
```html
<!-- HTML -->
<div class="parent-container">
  <div class="child-box">정중앙 팝업</div>
</div>
```

```css
/* CSS */
.parent-container {
  /* 자식 요소의 left, top 배치의 기준점이 됨 */
  position: relative;
  
  /* 부모 요소의 크기가 명확해야 자식의 left: 50%, top: 50%가 정상 작동함 */
  width: 100vw;
  height: 100vh;
  background-color: #f0f0f0;
}

.child-box {
  /* 문서 흐름에서 벗어나 부모(.parent-container)를 기준으로 자유롭게 이동 가능해짐 */
  position: absolute;
  
  /* 자식 요소 본연의 영역 크기 지정 */
  width: 300px;
  height: 200px;
  background-color: white;
  
  /* 1단계: 부모 요소의 가로세로 중앙 지점(50%)으로 자식 요소의 '좌측 상단 모서리'를 이동시킴 */
  left: 50%;
  top: 50%;
  
  /* 2단계: 자식 요소 '자기 자신의 크기'의 절반(-50%)만큼 좌측과 상단으로 끌어올려 정확한 중앙을 맞춤 */
  transform: translate(-50%, -50%);
}
```
