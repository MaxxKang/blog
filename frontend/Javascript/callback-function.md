# 콜백 함수

`forEach` 문을 공부하면서 이해한 것을 작성하려고 한다.  
그 중 콜백 함수에 관한 것이다.

## Call back 의 의미

함수의 특정한 모양이나 로직에 있는 것이 아니라, 다른 함수에게 자신이 언제 실행될지 타이밍을 맡긴다는 실행 흐름의 개념으로 이해하자.

콜백 함수는 함수가 코딩에서 사용되는 역할과 방식을 뜻하는 용어이다.  
어떤 평범한 함수라도 다른 함수의 인수로 전달되어서 "네가 필요할 때 나를 호출해(Call back)"라고 제어권을 위임하는 순간, 그 함수는 콜백 함수로서 동작하게 된다.

- 형태의 자유로움: 함수 내부에 `function() { ... }` 처럼 익명 함수로 직접 작성하든, 외부에 미리 만들어둔 함수의 이름만 넘기든 전달받는 쪽에서 대신 실행한다.
- 괄호 `()`의 유무: 괄호 없이 함수 자체를 넘기면 제어권을 위임하는 콜백 함수가 되고, 괄호를 붙이면 함수가 즉시 실행되어 그 결과값만 전달하게 되는 차이점이 있다.
