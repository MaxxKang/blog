# 반복문

## for

자바스크립트에서 가장 많이 사용하는 반복문이다.  
`for` 문은 초기화, 조건식, 증감식을 한 줄에 선언하여 지정된 횟수만큼 코드를 반복할 수 있다.
```javascript
for (초기값; 조건; 증감식) { ... }
```
적합한 사용: 반복 횟수가 명확하게 정해져 있거나, 루프를 돌면서 `i` 같은 인덱스 값을 직접 조작하고 계산에 사용해야 할 때 가장 기본적으로 사용된다.
```javascript
for (let i = 0; i < 5; i++) {
  console.log(i); // 0부터 4까지 출력
}
```

## forEach

배열(Arry)이 기본적으로 제공하는 내장 함수로, 배열의 첫 번째 요소부터 마지막 요소까지 차례대로 [콜백 함수](/frontend/Javascript/callback-function.md)를 실행한다.
```javascript
배열명.forEach(콜백 함수) { ... }
```
적합한 사용: 배열의 모든 데이터를 순회하면서 동일한 작업을 일괄 처리할 때 코드가 간결해진다.  
단, 중간에 `break`나 `continue`로 반복을 멈출 수 없으니 끝까지 순회해야 하는 경우에만 사용한다.
```javascript
const arr = ["a", "b", "c"];
arr.forEach(item => {
  console.log(item); // a, b, c 순차 출력
});
```

## for...in

객체(object)가 가지고 있는 열거 가능한 속성 이름(key)을 순회해서 꺼내온다.
```javascript
for (변수 in 객체) { ... }
```
적합한 사용: 배열이 아닌 객체 내부의 키(key)와 값(value)을 확인할 때 적합하다.  
배열에 사용하면 인덱스가 숫자가 아닌 문자열로 반환될 수 있어 배열 순회용으로는 권장되지 않는다.
```javscript
const obj = {name: "강문호", city: "대구"};
for (const key in obj) {
  console.log(key, obj[key]); // name 강문호, city 대구
}
```

## for...of

배열, 문자열 등 반복 가능한(Iterable) 객체의 실제 데이터를 순회해서 가져온다.
```javascript
for (변수명 of 반복 가능 객체명) { ... }
```
적합한 사용: 인덱스 번호는 필요 없고 배열이나 문자열 안에 있는 값 자체만 순서대로 필요할 때 `for` 문보다 훨씬 직관적으로 작성 가능하다.  
`forEach`와 달리 `break`도 사용 가능하다.
```javascript
const arr = [10, 20, 30];
for (const value of arr) {
  console.log(value); // 10, 20, 30
}
```

## while

소괄호 안의 조건이 참(true)인 동안 내부 코드를 계속해서 반복 실행한다.
```javascript
while (조건) {
  실행할 명령
}
```
적합한 사용: 시작할 때 몇 번을 반복해야 할지 알 수 없고, 특정 조건이 충족되거나 끝날때까지만 반복을 유지해야 하는 상황에 적합하다.  
블록 내부에서 조건을 거짓(false)으로 만드는 로직이 없으면 무한 루프에 빠진다.
```javascript
let count = 0;
while (count < 3) {
  console.log(count);
  count++; // 해당 증감식이 없으면 무한 루프 발생
}
```

## do...while

`while`문과 비슷하지만, 가장 큰 차이점은 조건식을 검사하기 전에 일단 내부 코드를 무조건 한 번 먼저 실행한다는 점이다.
```javascript
do {
  실행할 명령
} while (조건)
```
적합한 사용: 조건의 참/거짓 여부와 상관없이, 최초 한 번의 작업 실행은 반드시 보장되어야 할 때 사용한다.
```javascript
let x = 10;
do {
  console.log("최소 한 번은 실행됨");
  x++;
} while (x < 5); // x가 5보다 크지만 최초 1회는 실행됨
```

## break

실행 즉시 자신이 속해 있는 가장 가까운 반복문 하나를 완전히 종료하고 루프 밖으로 빠져나간다.  
적합한 사용: 원하는 데이터를 이미 찾았거나, 에러가 발생해서 더 이상 남은 반복을 진행할 필요가 없을 때 불필요한 연산을 막기 위해 사용한다.

## continue

반복문을 완전히 종료하지는 않고, 현재 진행 중인 회차의 나머지 코드만 건너뛴 다음 바로 다음 회차(조건식이나 증감식)로 넘어간다.  
적합한 사용: 특정 조건에 해당하는 데이터만 처리를 배제하고, 나머지 요소들에 대해서는 계속 반복 작업을 유지하고 싶을 때 유용하다.
